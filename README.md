# SaneCode Native

Native macOS workspace for running local coding agents, inspecting changes, and working with repositories.

## Build and run

Open `SaneCode.xcodeproj` in Xcode, select the application scheme, and choose a compatible destination. Configure your own signing team and bundle identifier if required, then build and run.
